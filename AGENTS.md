## Agent skills

### Issue tracker

issues 与 specs 作为 markdown 文件存放在本 repo 的 `docs/scratch/<feature-slug>/` 下。见 `docs/agents/issue-tracker.md`。

### Triage labels

五个 canonical triage roles：`needs-triage` / `needs-info` / `ready-for-agent` / `ready-for-human` / `wontfix`，label 字符串与角色名相同。见 `docs/agents/triage-labels.md`。

### Domain docs

Single-context：根目录 `CONTEXT.md` + `docs/adr/`。见 `docs/agents/domain.md`。
